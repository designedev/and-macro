# 화면 매크로 (and-macro)

개인용 Android 화면 인식·자동 터치 앱입니다. 현재 버전은 **0.6.4 (versionCode 12)**이며 Android 16(API 36) 이상, 64비트 단말기를 지원합니다. 특정 게임이나 패키지로 대상을 제한하지 않습니다. 사용자가 캡처에 동의하고 대상 앱으로 이동한 뒤 실행합니다.

## 주요 기능

- 한국어·영어 OCR 문구의 정확 일치/포함 일치 또는 기준 이미지 비교로 대상 검출.
- 여러 매크로 동시 감시, 목록 드래그 우선순위, 매크로별 클릭 간격·전후 대기.
- 기본 전체 화면 검색, 필요할 때 캡처 화면에서 드래그로 범위 지정. 숫자 좌표 입력 없음.
- 클릭 없는 인식 테스트와 이미지 기준 등록·자르기.
- 이동·위치 저장·접기가 가능한 작은 오버레이 카드와 ASCII 실행 스피너.
- 실행 중 최저 밝기, 카드 터치 즉시 원래 밝기로 복구, 종료 시 복구.
- ‘어둡게’ 적용 성공 시 카드 자동 접기. 실행 중 정지 버튼은 펼친 카드에만 표시.
- Room을 통한 매크로·우선순위 저장. 기준 이미지와 설정은 앱 전용 저장소에 보관.

## 동작 방식

새 캡처 프레임을 한국어·영어 ML Kit OCR로 읽거나, 회색조 이미지에 OpenCV `TM_CCOEFF_NORMED` 템플릿 매칭을 적용합니다. 이미지 유사도 기본 임계값은 0.90이며 확률을 뜻하지 않습니다. 같은 영역의 여러 문구 조건은 OCR 결과를 공유합니다. 유효한 후보가 하나일 때 접근성 제스처로 중심을 터치하며 복수 후보·오버레이 영역에는 클릭하지 않습니다.

조건이 없으면 인식 완료 뒤 500ms 대기하고 다시 검사합니다. 실제 검사 주기는 캡처·인식 시간만큼 더 길어집니다. 클릭 간격은 별도로 기본 3초·최소 1초입니다. 다중 실행에서는 클릭 가능한 조건 중 목록 위쪽부터 실행하며 상위 조건이 없거나 대기 중이면 다음 순위를 검사합니다. 한 번 터치한 뒤 다른 조건의 이전 좌표를 쓰지 않고 새 화면을 검사합니다.

1초가 지난 결과는 클릭하지 않습니다. 프레임 수신이 끊기면 기존 캡처 세션의 수신 표면을 한 번 교체해 복구를 시도합니다. 상단 알림 팝업이나 펼친 알림창에서는 클릭을 일시 보류하며 같은 대상 앱·창이 확인되면 새 프레임으로 재개합니다. 클릭 전 대기도 다시 적용하고 개별 클릭 간격은 유지합니다. 알림 대기는 인식 오류로 세지 않습니다. 실제 다른 앱·창 전환, 회전, 잠금, 캡처 종료, 접근성 해제 또는 연속 인식 오류는 세션을 종료합니다. 실제 게임의 보호 화면이나 제스처 제한을 우회하는 기능은 없습니다.

밝기 변경에는 Android ‘시스템 설정 변경’ 특별 접근 권한이 필요합니다. 복구할 밝기·자동 밝기 모드를 먼저 저장합니다. 프로세스 강제 종료나 전원 종료 시 즉시 복구는 보장되지 않으며 다음 앱 실행에서 재시도합니다. 게임 부스터의 자동 터치 방지는 별도로 해제합니다.

## 개발 환경과 빌드

- JDK 17
- Gradle wrapper 8.13 / AGP 8.13.2 / Kotlin 2.2.10
- Android SDK 36.1 / compileSdk 36.1 / targetSdk 36 / minSdk 36
- arm64-v8a, x86_64
- Compose BOM 2025.08.00 / Room 2.7.2
- OpenCV 4.13.0 / bundled ML Kit Korean·Latin 16.0.1

Android Studio에서 저장소 폴더를 엽니다. SDK 경로는 IDE에서 설정하거나 로컬 `local.properties`의 `sdk.dir`로 지정합니다.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk`에 생성됩니다. Gradle wrapper와 소스는 저장소에 포함하지만 APK·SDK 경로·빌드 캐시·IDE 개인 설정·서명 키는 포함하지 않습니다. 의존성 최초 다운로드에는 네트워크가 필요하며 앱 실행에는 인터넷 권한이 없습니다. 현재는 검증용 debug 빌드이고 개인 키로 서명한 release 배포는 별도 단계입니다.

Android 테스트는 테스트 전용 에뮬레이터에서 실행합니다. `connectedDebugAndroidTest`는 연결된 기기를 대상으로 하므로 개인 단말기와 테스트 환경을 확인한 뒤 실행하세요. 네이티브 라이브러리 정렬은 다음 명령으로 검사할 수 있습니다.

```sh
python3 scripts/verify_apk.py app/build/outputs/apk/debug/app-debug.apk
```

## 검증 상태

2026-10-03 기준 단위 테스트 68개, 전체 Android 테스트 15개 통과. 실제 시스템 상단 알림·펼친 알림창 분류와 원래 창 복귀를 검증했습니다. Lint는 오류 0·경고 24개입니다. 실제 Galaxy Android 17 기기에서 사용자가 0.6.0 정상 동작을 확인했고, 최종 0.6.4를 설치했습니다. 알림 일시 대기·복귀 후 재개의 실제 Galaxy 게임 확인은 별도입니다.

자세한 내용은 [검증 기록](docs/VERIFICATION.md)과 [밝기·오버레이 변경 기록](docs/BRIGHTNESS-OVERLAY.md)에 있습니다. 문서에서 참조하는 `outputs/`는 로컬 빌드·시험 산출물이며 Git에서 제외합니다. APK 배포와 GitHub Release는 아직 생성하지 않았습니다.

## 프로젝트 구성

- `app/src/main`: 캡처, 접근성 제스처, 인식, 밝기 제어, 저장소, Compose UI.
- `app/src/test`: 핵심 실행·타이밍·창 정책·밝기 복구 단위 테스트.
- `app/src/androidTest`: 인식, 저장·우선순위, 밝기·오버레이 UI 테스트.
- `docs`: 사용법, 서명 방법, 구현·문제 해결·검증 기록.
- `scripts`: APK 네이티브 정렬 검사.

## 사용과 데이터

[설치·사용 안내](docs/INSTALL.md)를 따라 접근성·알림·시스템 설정 변경을 허용하고 매 세션 전체 화면 캡처에 동의합니다. 캡처 동의와 대상 앱 선택은 자동화하지 않습니다.

전체 화면은 메모리에서 처리하고 기준 이미지 자르기를 적용했을 때만 해당 이미지를 저장합니다. 실행 로그에는 OCR 원문·화면 이미지를 기록하지 않습니다. 최근 1,000건을 메모리에 유지하며 프로세스 종료 시 사라집니다. debug 빌드는 상태·처리 시간·오류·제스처 전달을 Logcat에도 기록합니다. 앱 백업은 비활성화되어 있으며 삭제하면 설정과 이미지가 사라집니다. 개인 키 전환과 업데이트는 [서명 안내](docs/SIGNING.md)를 참고하세요.
